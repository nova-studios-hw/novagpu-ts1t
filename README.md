# What is this?

NovaGPU TS1T is an experimental GPU architecture written entirely in Verilog RTL.

The goal is not to compete with NVIDIA or AMD.

The goal is to learn, experiment, test ideas, break things, fix them, and see how far a single open-source GPU project can go.

Everything is being developed publicly.

Sometimes things work.

Sometimes they explode.

That's part of the fun. xd
